## Delivery and review

Signal Grid exposes native color pickers and editable hex inputs for Paper, Ink, Muted, Rule and Accent. Valid values update the existing same-origin preview in place; invalid drafts preserve the last valid color, reset returns the original palette, and edits last only while the system page is open. `preview-palette.js` applies scoped custom properties to the embedded preview document; preview-only aliases inside `conare-home-source.jsx` propagate them across the ten source section shadow roots, and the existing outer navigation and token CSS use fallback-preserving variables. The accent alias changes the source SVG paths that use its color token. Logos, photos and independent fixed shades do not all recolor. Other systems, typography and spacing remain read-only because their corresponding preview mappings have not been implemented or verified.

Source screenshot and code were inspected by `/root/color_visual_analysis`, `/root/color_product_design`, and `/root/color_art_direction`. Art direction identified a delayed heading accent due to the source's staggered transition; the edited preview now updates that accent immediately. Desktop and mobile captures are in `pilot/evidence/live-foundation-colors/`. Browser tests in that directory cover all five roles, native color inputs, valid and invalid hex, reset, tab changes, a preserved selected demo/scroll/iframe, and edits made before the iframe load. Original and editable default preview screenshots had identical SHA-256 and foreground/background/border computed styles matched for 3,774 visible elements across 11 roots.

Independent QA `/root/color_independent_qa` passed the delivered revision at 320, 390 and 1440px, including all five color roles across ten shadow roots, reset, input validation, keyboard focus, tab order, preview state, pre-load edits, unmodified standalone source, and a read-only Blueprint fallback. Headless Chromium could not inspect the operating-system color picker dialog itself. Production build passed with the existing large-chunk warning; all nine system pages passed tab-content smoke checks.
