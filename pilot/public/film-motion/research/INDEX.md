## Tool investigation and validation

[REA provenance](rea-provenance.json) pins the repositories and records selected-file coverage. HyperFrames and FFrames editor JavaScript/TypeScript received actual REA analyses; native Rust paths were traced directly from source. These are partial repository analyses, not speed measurements. Native-wgpu integration guidance is source-verified research and a proposed architecture, not a newly implemented renderer.

[Validation notes](validation/validation-notes.md) record the official skill validator, CFR/VFR analyzer fixtures, repeat/fractional/reverse seeking, a one-second browser calibration export, and an independent behavioral forward test. The calibration verifies operation, not target artistic quality.

Raw media, alternate sheet layouts, repository clones and REA evidence remain project-local. The distributable skill contains compact metadata, detailed text studies, guides, helper and browser starter; it excludes those large raw assets. Reference downloads are for study and do not grant commercial reuse rights.
