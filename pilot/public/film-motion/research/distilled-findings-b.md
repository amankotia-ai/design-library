# Skill integration notes from studies B and A-tail

Evidence: [B:16posts/18assets](reference-study-b.md), [A-tail:8posts/8assets](reference-study-a-tail.md). All 19,836 decoded frames across these 26 assets were scanned as 208 consecutive-frame thumbnail sheets. Eighteen selected source-size stills were opened separately. This does **not** establish full-resolution all-frame inspection, playback, or listening; no audio-derived rules were extracted.

## Editorial direction

The strongest useful mechanisms are information hierarchy, a clear artifact, deliberate negative space, tactile or typographic assets, and a reason for the next state.

- **Quiet information needs actual screen time.** Tensorlake B12 f181–419 holds code and flanking explanations; iamcfw A13 f210–250 uses a small three-row process list; Outset B10 f811–900 holds a poster. Make read time an explicit timeline state rather than incidental spare time after movement.
- **Assets can carry the story through many surfaces.** TasteGraph A15 f129–249 takes one poster from a saved/selected state into a review composer and a split artifact/review layout. B16's Linear film keeps the same review case through list, code, guide, comment, and submission. Use continuity of real case/data to connect scenes.
- **Tactility comes from curated asset relationships.** TasteGraph A15 f21–49 combines a cutting mat, raster/paper cuts, overlap, photography, and scale variety. A generated asset library needs an art bible: consistent edges, lighting, shadow, texture, cropping, and intended size. The source does not prove imagegen use.
- **One geometric system can support a whole editorial world.** Outset B10 turns stripe spacing into lockup, expanding rectangle, photo mask, poster, and repeating pattern. Specify the new brand's own module relationships before making individual scenes.
- **Backgrounds have a script.** iamcfw A13 uses diffuse warm/cool color as opening/closing mood, pale information chapters, one dark chapter, and a gradient thumbnail that later becomes the environment. It is not a different arbitrary background per shot.
- **Stepped motion is an authored cadence.** TasteGraph is encoded at15fps and includes discrete cutout substitutions. This suggests held scene states per layer, not lowering all final-output frame rates or making important type judder.

## High motion direction

The strongest useful mechanisms are meaningful transformation, density change, clear trajectory, contrast in scale, and a fully resolved target.

- **Persist a primitive through related meanings.** Tracelight B01 f8–104 builds seed→assembly→mark→wordmark. Outset B10 f220–650 expands the mark into content and returns it to the mark. A transform should preserve identifiable properties, not merely hide a cut with arbitrary blur.
- **A transition baton can cross abstract and product space.** Fomo A10 carries a small branded disc from a selected row into an identity field and later from an order action onto a chart. It ties the sections together without making every UI panel fly.
- **Many can become one useful abstraction.** Ramp B03 f77–235 turns scatter into a brand/system; Fomo A10 f930–1029 turns many trading pills into three metric bars. Ensure that the transformed objects have a truthful conceptual relationship.
- **Cut for a changed chapter; transform for continued identity.** Bitstack B07 alternates giant type, logo construction, real applications, rendered coins, UI, and identity holds. The chapter vocabulary is shared even when the media changes.
- **Energy requires recovery.** Tracelight B01 pauses the settled silhouette between changes; Bitstack B07 f329–390 and f1611–1768 rests on identity; icyyfx A14 f540–648 holds a pale brand frame after the results. Program anticipation, transition, settle, read, and exit explicitly.
- **Palette pairs beat random saturation.** Outset's forest/lime, purple/peach and cyan/navy pairings are intentional scene states. AutoBot B05 gives mint/violet/pink/yellow distinct semantic roles. Keep those roles consistent within a new film.

## Cinematography and UI proof

- Name the actual visible behavior: object rotation, global scene translation, scale/reframe, perspective tilt, or camera orbit. Jay's globe B09 rotates within a stable page frame; Outset B10 is overwhelmingly frontal2D composition. Neither needs a cinematic orbit label.
- A camera move earns its place by revealing information or changing conceptual scale. AutoBot B05 moves organization→worker→responsibility→event. Linear B16 follows the task's hierarchy. Record the attention target and newly revealed information in every camera brief.
- Use beauty framing and proof framing for their own purposes. Postiaux A11 cuts from a physical monitor to a direct UI crop for the heatmap interaction; Linear B16 becomes more frontal during guide/code evidence. Perspective, blur, and shadows must not obstruct proof.
- Stage cursor interaction as approach→action→expandedstate→selection→result→exit. AutoRouter B14's attached menu anchor stays stable while the list scrolls; icyyfx A14 completes the prompt before approaching submit and showing results.
- Dark material requires value separation. EthenaPay B04 and Bitstack B07 use curved geometry, thickness, grazing highlights, and controlled specular edges. A broad glow is not a substitute for a deliberate material/light rig.

## Finishing modes to make explicit

| Mode | Evidence | Production choices to decide before rendering |
|---|---|---|
| Crisp graphic | Outset B10 | Vector edges, type alignment, masks, palette pairs, motion blur policy |
| Tactile editorial | TasteGraph A15 | Cutout edge quality, paper/image texture, overlap, shadow consistency, stepped cadence |
| Pale product plane | AutoRouter B14; icyyfx A14 | UI fidelity, subtle border/contact shadow, rounded geometry, legible native cursor |
| Dark material | EthenaPay B04; Bitstack coin chapter B07 | Geometry, roughness, metallic response, key/rim light, dark-value separation |
| Atmospheric gradient | Elio B13; iamcfw A13 | Warm/cool zones, value field under text, linear/high-bit-depth working pipeline, dither/banding checks |
| Cinematic UI macro | Linear B16 | Perspective by phase, attention path, exact readable proof, selective focus rather than blanket blur |

These are proposed new-film implementation decisions. Visual inspection does not identify the original renderer, GSAP use, lens model, shader, font implementation, or render speed. A wgpu backend should preserve scene/timing semantics and be benchmarked against a representative scene suite; source resemblance is no performance evidence.

## Reference literacy required in the skill

Do not train a single linear story from simultaneous panels. B02 dipvizz, B04 unused EthenaPay shots, B08 Causal studies, A09 driceroland, and A12 Benjamin are four-up boards; A16 Alim is nine-up. B06 is a Figma process recording, B09 a globe prototype, B12 a component reel, and B13 three distinct gradient variants. B16 is a video inside a quoted Karri Saarinen post, not a native Peer Richelsen attachment. Classify each source and preserve the quote/asset relationship before extracting narrative rules.

Audio remains unreviewed in both these batches, including A10's explicit sound-design exploration. The skill should create an audio-event map and require actual listening, but no claim that these references demonstrate a particular sound cue, BPM, voice performance, or mix should be added from this evidence.
