# Reference library

Read this index to select relevant studies. Then read only the matching source-specific sections. Evidence was collected on 6 November 2026. The full MovieMaker project retains original metadata/media, source hashes, decoded-frame CSVs, thumbnail sheets, and actual review coverage. Large evidence assets are not bundled in the portable skill.

## How to use the evidence

The supplied collection contains whole films, identity explorations, prototypes, unused shots, and simultaneous multi-panel reels. Keep those roles distinct. A beautiful 5-second loop can teach choreography without supplying a complete film argument. An official product account does not independently validate its marketing claims; a repost does not establish authorship.

The X studies and Memorable received every-frame thumbnail scans, with selected larger stills/windows. This is granular chronological visual evidence, not native-resolution inspection of every frame or original-speed playback/audio review. Soundtrack and perceived smoothness were not reviewed in this research. Do not invent reference music, narration, beat sync, exact curves, or creator tools from the images.

Source studies are grouped for navigation:

- [Studies A01–A08](studies-a.md): Leap, BuffetDesigns, XRarchitect, Runinfra, Motionstash, Leo, Arav Srinivas, and ClaudeDevs.
- [Studies A09–A16](studies-a-extra.md): driceroland, Leo, PostiauxCharles, BenjaminUIX, iamcfw, icyyfx, bykarnsarao, and alimdesigner.
- [Studies B01–B16](studies-b.md): primitive transformation, explanatory reels, Ramp, EthenaPay, AutoBot, Figma process, Bitstack, Causal, identity systems, vector animation, diagrams, background treatments, routing, and Linear.
- [Portfolio studies](portfolio-studies.md): the Memorable film, the 32-entry Skale inventory, and three explicitly sampled portfolio excerpts. The remaining Skale portfolio films were not individually frame-analyzed.

## Select by the problem a shot must solve

| Problem | Relevant observed example | Transfer |
|---|---|---|
| A motif should explain the product and resolve into identity | Memorable's maze→stored paths→recall graph→route/symbol | Reuse a meaningful relationship through the argument, not merely a recurring logo |
| A primitive needs to become a brand object | B01 Steve Lauda, f0–104 | Stage seed, separation, assembly, frontal mark, then quiet lockup |
| A system needs visible direction | B02 dipvizz's processing graph; B03 Ramp's workflow | Reveal inputs, connection, operation and output in a traceable order |
| A problem should be enacted before the solution | B03 Ramp, f77–235 | Increase disorder, then establish organizing geometry; do not merely label the problem |
| A dark material needs separation | B04 EthenaPay; B07 Bitstack coin passages | Design grazing/rim light, curvature, roughness and negative space before adding glow |
| A complex agent needs a clear conceptual model | B05 AutoBot, f220–610 | Separate responsibility, goal, tools, budget, permissions and event handling |
| A list needs one active item | B06 Figma process; B07 action list | Couple active-item scale/width/position and keep inactive items as context |
| Many media types need one identity | B07 Bitstack | Carry a bounded palette, motifs and type across applications, objects and UI |
| A metaphor needs to return to tangible output | B08 Causal | Alternate abstract image with recognizable report/product state; articulate the causal link |
| A founder and graphic explanation need to coexist | Skale TypeSafe and Baseten excerpts | Give presenter, type and diagram separate jobs within a shared graphic system |
| Human interaction can carry the concept | Skale Cognition excerpt | Use reaction framing, selective attached overlays and dialogue structure; this study did not listen to performance |
| Human delegation needs a visible consequence | A07 Perplexity Teammates | Carry a task between people and let the agent's work change what each person can do |
| A material-led reveal needs coherence | A01 Leap | Reuse one surface language at several scales; reserve the richer product palette for the reveal |
| A full object reveal needs to feel earned | A03 World Labs Frameboy, quoted by XRarchitect | Reveal switch, controls, screen and physical input before the full spatial view and live output |
| Technical mechanism, case and offer need one vocabulary | A04 Runinfra | Carry grid, accent block, caret and masks through explanation, statistics, pricing and code; verify claims separately |
| Product context changes around one identity | A05 Notion study | Preserve content/identity while its container and surrounding scene change in separate phases |
| Connection can be explained without camera travel | A08 ClaudeDevs | Draw incoming relationship, intermediary, outgoing branches and completion in causal order |
| Identity should generate the editorial system | B10 Outset Law | Reuse one module as mark, divider, viewport, photo mask and pattern; plan palette pairs |
| A gradient needs to support the foreground | B13 Elio's three distinct variants | Give the ground a slower rhythm and inspect ramps/banding at actual output resolution |
| A feature demonstration needs distinct interaction beats | B14 AutoRouter | Separate cursor approach, action, expanded state, selection, result and exit |
| A graph build should end in a long rest | B15 graph experiment | Stage anchor, relationships and outputs, then stop moving while the relationship is understood |
