# Speech, picture & the edit clock

Map a source-word anchor into program time, then inspect picture-cue offset and frame quantization.

## Explore the example

Change one input at a time and watch the scene, plot and measured result together. The visual is computed from the same functions as the values shown. The equation is visible above the example; its definitions and assumptions appear below.

## Read the mathematics

The example is an authored mathematical model, not an inferred model of an arbitrary video. Units, parameter limits and model-specific caveats are shown with the controls. Use the diagram to test a concrete choice and the source functions to reproduce the calculation.

## Reuse the functions

The dependency-free JavaScript functions are available from the References tab. They are exported from `film-timing-math.js`. The library includes checks of derivatives, limiting cases or invariants appropriate to each model.

## Evidence and interpretation

The interactive approach is informed by [The Calculus of Interfaces](https://calculus-of-interfaces.vercel.app/). Each film example is authored for this library. Geometric containment, signal arithmetic and timing calculations do not establish emotional impact, comprehension or artistic quality. Reading rates and semantic timing targets are explicitly chosen assumptions.
