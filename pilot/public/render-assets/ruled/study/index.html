Reading the grid

The header, text, and images need a few edges to share. Start there, then decide which columns to leave empty and which parts of the page deserve more room.

The examples below use the same system as the playground. Change one thing at a time to see what it contributes.

A few shared edges

Shared edges do not mean equal widths. In this project study, the paragraph and metadata occupy two columns. A third column stays empty before the photographs begin.

The images share a horizontal band, while the small information rail sits near its lower edge. The narrow text and the generous photography each have their own scale.

Two columns for text, one empty column, then photographs spanning five and four.

The horizontal lines have a rhythm too. With a 4 px base unit and an eight-unit row module, each row is 32 px high. A block starts at a whole row index and occupies a whole number of rows.

Space is part of the layout

Not every column needs content. Leaving the first one empty gives a paragraph a clear position on the page. It also creates distance between the utility header and the story below it.

The paragraph still has enough room to read. The empty column is a deliberate part of the composition, rather than whatever space happens to be left over.

The three-column text measure stays the same. The text and image move together by one column.

The makes that empty first column visible. The text spans the other three.

Let the image set the scale

A large photograph does more work than a large interface around it. Keep the supporting type small, let the image occupy a decisive area, and align its caption to the same edges.

Images can share a top edge without sharing a crop. Here a four-column image changes shape beside a second four-column landscape. A two-column paragraph sits apart from both.

Change the first crop. The second image and the narrow text rail stay in place.

The use large image areas, narrow information rails, and related crops to make very different subjects feel connected.

Recompose for a smaller screen

A smaller screen needs a different reading sequence. On desktop, two columns hold the information and one stays empty before the photographs span five and four columns. The photographs share the same top and bottom edges.

On mobile, the photographs move above the information and split the four-column grid three to one. The paragraph and project details keep a three-column measure beneath them.

Desktop: 2 + 1 empty / 5 / 4. Mobile: 3 / 1, with the information below.
