One calculation drives the map and export

UI width = canvas width × shot width fraction
UI height = UI width × capture height ÷ capture width

Whole-window shots must fit without shrinking below their width policy. A component capture does not become an app viewport.

Close-up placement protects the real content

Start at the declared anchor; solve the permitted position from the heading, chart and account evidence. Stop when those constraints cannot fit.

The close-up anchors to protected content. Artwork survives in the resulting margins; it does not dictate a narrow side placement.
