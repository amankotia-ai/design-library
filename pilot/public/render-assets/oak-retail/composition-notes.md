# Oak retail family: five new compositions

These are **new generated compositions**, requested as extensions of the warm oak/stone family in the [Vadim Carazan reference](https://x.com/VadimCarazan/status/2114623816072568925). They do not depict additional images from that tweet. The original four are phone-on-desk, auditorium display, five social cards and laptop sticker; this set changes both subject and composition.

Shared visual language: natural light oak grain, pale warm stone/concrete, ivory paper/canvas, brushed aluminium and soft directional daylight. Keep materials tactile, backgrounds quiet and application surfaces clear. Avoid strong orange grading or importing the source brand's green artwork. Use these as fixed photographic plates; actual camera/lighting changes require geometry reconstruction or a newly generated composition.

## Blender and imagegen usage

The library `assets/oak-retail-extension/oak-retail-plates.blend` contains five scenes and eleven transparent local **safe-area guides**. `slots.json` records native 1672×941 pixel corners and artwork sizes. Subdivided projective UVs reduce the diagonal affine distortion that a single screen-space quad can introduce. These are camera-space placement aids, not complete object models, exact masks or finished lit print materials. The tote still needs cloth deformation and the glass still needs an appropriate reflection/transmission treatment when populated.

Copy a plate/scene into the task workspace. Inspect the actual selected image and the repo's product/brand evidence, resolve its dependency recipe, create missing artwork, show the assets, then compose. Use the **generated plate itself** as the primary reference when recreating these layouts; the tweet images are supporting material/mood references only. The self-contained pack preserves the two actual style inputs and the user's family overview. For imagegen label their roles explicitly so it does not regenerate the original phone or auditorium composition.

Native generated PNG detail is **1672×941**, approximately 16:9. A larger Blender export alone does not add photographic detail. For a square/portrait request reframe, extend or recompose without distorting the subject or local art. New broad scenery beyond the plate requires generation or geometry; keep the output contract and resolution provenance accurate.

Before delivery, perform [independent finishing review](visual-qa.md) on each actual branded output. Blank-plate acceptance covers empty-surface cleanliness, composition and physical plausibility only. It does not certify future artwork fit, print shading, occlusion or a full-bleed mask.
